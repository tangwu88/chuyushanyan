## 启动、停止与验证

本机为 Apple Silicon Mac，独立 Java 21、Maven 与 MySQL 8.4 位于 .tools，数据位于 .runtime/mysql，均不写入源码管理。

```sh
python3 scripts/bootstrap.py
python3 scripts/dev.py build
python3 scripts/dev.py start
python3 scripts/dev.py status
python3 scripts/dev.py stop
```

build 执行 Java 测试与打包、两个前端的类型检查和构建。Node 22 与 pnpm 11 可使用 Codex 本机提供的依赖，或自行安装。bootstrap 下载来源和 SHA256 固定在 scripts/toolchain-lock.json，不修改系统 Java 或启动配置。

```sh
CHUYU_API=http://127.0.0.1:18080/api/v1 pnpm test:api
python3 scripts/performance.py
python3 scripts/database.py backup
python3 scripts/database.py restore-check
```

接口验收会创建合成业务、发布演示规则和调整测试配置，请对独立验收库启动的后端运行；`CHUYU_API`指定该后端地址。规模测试也支持`CHUYU_API`与`CHUYU_DB`，临时生成20万订单和20万零金额流水，完成后删除本次数据。恢复验证使用单独的 `chuyu_restore_...` 库，不覆盖演示库。

## 容器部署

```sh
docker compose up --build -d
docker compose logs -f backend
docker compose down
```

容器默认同样使用独立演示配置和本地端口。数据库卷会保留。原生服务与容器服务使用相同端口，切换前先正常停止另一种启动方式。

## 工程结构

- backend：Spring Boot 4.1.2、Java 21、MyBatis Starter 4.1.0、Flyway；按会员、订单、资金、奖励和报表分包。
- apps/admin：Vue 3、TypeScript、Element Plus。
- apps/h5：Vue 3、TypeScript、Vant。
- packages/shared：接口客户端、状态文案、金额显示；金额使用字符串传输，浏览器按整数分处理。
- scripts：独立环境准备、进程管理、接口验收、数据规模测试及备份恢复。
- docs：脱敏业务来源、决策、接口和验证证据。

## 演示边界

需求未给出比例的五类身份采用显式标注的演示比例，见 docs/DECISIONS.md 和规则中心“待确认规则”。正式支付适配器、银行出款、短信、快递轨迹与生产环境上线需分别接入和验收。

当前数据库写操作由同一个数据库锁保证演示一致性，支持多进程防重复。交易量扩大后，可保留领域接口，将这一锁改为钱包、订单和账期各自的锁及重试机制。账本与规则版本的历史记录不覆盖修改。
